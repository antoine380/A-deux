# À Deux

Application web privée pour Stéphanie et Antoine : parcours, rituel du jour, mode Soirée, jeux, envies communes et journal.

- Site statique, aucune étape de build : Netlify publie le dossier tel quel (voir `netlify.toml`).
- Les données restent dans le navigateur de chaque téléphone. Les envies s'échangent avec le code d'échange (onglet Envies).
- Chaque push sur `main` met le site à jour automatiquement.
